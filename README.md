# Todo List App

A simple persistent command-line todo list written in pure Python.

## Requirements

- Python 3.6+

## How to run

```bash
python todo.py
```

## Commands

- `add Buy milk` — add a new todo
- `list` (or `ls`) — show all todos
- `done 1` — mark todo #1 as done
- `delete 2` — remove todo #2
- `quit` — exit

Todos are saved automatically in `todos.json` next to the script.
